# P2-8: geresh and gershayim fixes for the live DB

Source: the live artifact DB (`athletes` 100, `competitions` 84, `sports` 33), read 2026-10-18.
The published `site/data.json` is already clean, because `job/export_data.py` normalises on export. These
fixes are for the DB itself, which is what editors see and what the review queue and `#admin` read.

Rule: an apostrophe-like character (`'` `’` `` ` ``) right after a Hebrew letter becomes geresh `׳`.
A `"` between two Hebrew letters becomes gershayim `״`. English text, `name_en`, URLs and `source`
fields are never touched. A quote that opens before a Hebrew word (for example `'מאי 2027'`) is a
quotation mark, not a geresh, so it is left as is.

To apply:
- `history[0].text` sits inside an array, so write the whole `history` array back with the same entries
  and only the text changed.
- Pin every write with `if_version`.
- The daily job writes these characters, so `job/SKILL.md` should tell it to use ׳ and ״. Otherwise
  the fixes will regress.
