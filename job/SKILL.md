DATA MODEL (display text in Hebrew):
- sports/<sportId> (kebab English, e.g. judo, artistic-gymnastics): {he, en, window: {from, to|null, summary, source} | null}
- athletes/<kebab-id>: {name, name_en, sportId, sport (Hebrew, legacy), event, stage (0 tracked, 1 in active qualification window, 2 Olympic quota/berth earned, 3 officially selected), rank, next, nextDate (YYYY-MM-DD), notes, source (https url), rankNum (int ≥ 1 or null) + rankList (official list name in English, as the IF writes it) + rankAsOf (YYYY-MM-DD, the list's date) — the world ranking, optional, all three set together, olympicRankNum + olympicRankList + olympicRankAsOf — the same for the Olympic qualification list, optional, all three set together, history: [{at: YYYY-MM-DD, kind: "start"|"stage"|"rank"|"result"|"next"|"note", text (short Hebrew), source}] (max 20, oldest dropped), archived (optional), updatedAt (ISO with Z), updatedBy ("auto" for you; anything else = a human), verifiedAt (ISO) + verifiedBy (viewer id): set only by a human in the page}
- competitions/<kebab-id>: {sportId, sport (legacy), name, location, start, end (YYYY-MM-DD), qualifying (bool), notes, source}. Store multi-stop series (World Cups) as separate competitions per stop.
- proposals/<id>: {kind: "update"|"create", target: <athlete id>, patch: {...}, summary (one Hebrew line), evidence: [{url, label}], status: "pending"|"approved"|"rejected", createdAt, correction?: {by: "job", reportedAt (ISO with Z)}}
- corrections/<id>: the public corrections log. Written only by the page (editor save or approving a proposal that carries `correction`). NEVER create, change or delete corrections docs yourself; only list them for the export (step 5b).
- runs/<YYYY-MM-DD>: {status: "started"|"done"|"failed", started, ended, sportsChecked, writes: [{collection, id, fields}], proposals: [ids], published: bool, errors, warnings, changes: [meta lines added this run], sources: [{source, checkedAt, sportId?}]}. Built only by run_log.py (step 0 and 6); #admin reads it.
- TIME: never type a timestamp. Every "now" (started, ended, lastRun, checkedAt) comes from: python3 ~/.claude/scheduled-tasks/la28-israel-daily-update/run_log.py now  → {"now": UTC ISO with Z, "today": Israel date}. Israel time written with a Z is a bug.
- meta/status: {lastRun (ISO with Z), changes: [{at: YYYY-MM-DD, text, athleteId?}]} — newest first, max 30.
